Nico's Shiny Pokemon Database

This Database stores all of the Shiny Pokemon I have caught throughout playing various Pokemon game titles.
It stores all information about them such as how they were caught, when they were caught, if they were given to me
and basic information like their levels, types and game of origin. This database also lets you see which Pokemon were
boosted or not when caught, search for specific words in ability description, and see how many Pokemon have a specific
boosted nature depending on what status you would like to see. Lastly there is a feature that allows you add a new
shiny Pokemon following the proper guidelines as you fill out the information.
